# HTML-презентация для выступления

Автосборка из каталога `in/` в `out/`.

**Формат входных данных:** [IN_FORMAT.md](IN_FORMAT.md) — требования к `slide.md` и медиафайлам.

**Для AI-агента из другого проекта:** [README_for_agents.md](README_for_agents.md) — как подготовить **один** `slide.md` на проект.

## Быстрый старт

```bash
pip install -r requirements.txt
python build.py
```

Откройте `out/index.html` в браузере, нажмите **F11** для полноэкранного режима.

**Онлайн:** https://timptr42.github.io/show/

Навигация: клик по правой половине экрана / кликер — вперёд, левая половина — назад. Стрелки на клавиатуре тоже работают.

## Структура `in/`

| Папка | Назначение |
|-------|------------|
| `00-welcome` | Приветствие: заголовок из frontmatter, фоновые видео из папки |
| `01-…` … `NN-…` | Блоки выступления (`type: talk`) |
| `99-questions` | Финальный экран |

В каждом блоке — **`slide.md`**. Каждый заголовок `##` — отдельный слайд (порядок как в файле). Медиа подключаются ссылками `![](file.png)` или тегом `<video>`; неиспользованные файлы из папки попадают на демо-слайды после секции `## Демо`.

Подробности — в [IN_FORMAT.md](IN_FORMAT.md).

## Сборщик

- Полностью очищает `out/`
- Копирует только медиа, на которые есть ссылки в MD (и остаток — в `## Демо`)
- **Не создаёт заглушки**
- Генерирует `out/index.html` и копирует результат в `docs/` (GitHub Pages)
