## Проблематика

При запуске Ленты столкнулись с проблемой разницы между суммой по позициям чека и итоговой суммой корзины. Для разбора требовалось анализировать текстовый лог, что занимало продолжительное время:

- логи по операциям очень объёмные — вручную их не просмотреть
- товарная корзина и фактическая сумма оплаты находятся в разных местах
- по одному чеку может быть несколько записей с разным статусом обработки

В итоге разбор одного случая занимал много времени.

## Что сделали

- единый инструмент с понятным интерфейсом — таблицы и вкладки, без работы «вслепую»
- автоматический поиск нужных фрагментов в отчётах
- сводка по чекам в одном окне

## Как создавали

Инструмент собирали с помощью **Cursor** (среда разработки с ИИ-ассистентом) и модели **DeepSeek** — для логики разбора отчётов, интерфейса и доработок по ходу проверки на реальных чеках.

- правила сравнения сумм и сценарии поиска чеков задавал автор по бизнес-логике
- ИИ ускорял написание и правки кода; итоговую проверку делали на боевых отчётах
- от идеи до рабочей версии — без отдельной команды разработки и длинного цикла согласований

## Решение

**Logos** сам находит все чеки в отчёте, выводит товары, скидки и фактическую сумму оплаты и показывает всё в наглядной таблице.

- собирает данные по чеку в одну карточку
- сравнивает расчётную сумму с фактически списанной
